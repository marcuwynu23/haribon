About Haribon

Simple traffic distribution for your backend services, with health checks and observability built in.

Overview

Haribon is a minimal, production-ready HTTP load balancer. It distributes incoming traffic across multiple backend servers using round-robin scheduling with health-aware filtering. Built for developers who need a lightweight reverse proxy without the overhead of complex configuration.

When to Use Haribon

Microservices Development

Route traffic across local service instances during development and testing. Haribon's round-robin scheduler distributes requests evenly, giving each instance equal load without manual coordination.

Simple Production Deployments

For small to medium-scale services that need request distribution without the operational complexity of traditional load balancers. Haribon handles health checking, structured logging, and graceful fallback with minimal configuration — just a YAML file and a single binary.

Observability Stacks

Haribon outputs structured JSON logs compatible with Loki and Promtail out of the box. Pair it with the included Docker Compose observability stack to get Grafana dashboards up in minutes.

Legacy Service Discovery

When you need a lightweight proxy fronting legacy services that lack built-in load balancing. Haribon's health-aware routing automatically skips unhealthy backends, providing basic resilience without invasive changes.

Key Benefits

  • Single binary — no runtime dependencies, no complex setup
  • Health-aware routing — unhealthy backends are skipped automatically
  • Loki-ready logging — structured JSON logs that integrate with the Grafana stack
  • Docker support — official image on GitHub Container Registry
  • Environment overrides — configure host and port via environment variables
  • Graceful fallback — falls back to stdout if log file creation fails

How It Works

Haribon listens on a configurable host and port, accepts incoming HTTP requests, and forwards them to your backend servers. Backends are selected in round-robin order — each request goes to the next available server, so no single instance gets overloaded.

Haribon keeps track of backend health automatically. Unhealthy servers are skipped until they recover. If all backends are down, Haribon returns a clear error so your clients know what happened. Everything is logged in structured JSON format, ready to feed into your observability pipeline.
