Installation

Choose the method that works best for you.

1

Build from Source

Clone the repository and build the binary.

git clone https://github.com/marcuwynu23/haribon.git
cd haribon
go build -o haribon main.go
2

Docker

Pull the official image from GitHub Container Registry.

docker pull ghcr.io/marcuwynu23/haribon:latest

Run the container:

docker run -d -p 4444:4444 ghcr.io/marcuwynu23/haribon:latest
3

Docker Compose (Full Observability Stack)

Start Haribon with Loki, Promtail, and Grafana in one command.

docker compose -f docker-compose.observability.yml up -d

This starts Haribon on port 4444 and three backend services on ports 4441-4443, plus the full Grafana observability stack.

Configuration File

Create a haribon-config.yml in your project root.

# haribon-config.yml
host: "0.0.0.0"
port: 4444

logging: true

backends:
  - url: "http://localhost:4441"
  - url: "http://localhost:4442"
  - url: "http://localhost:4443"

You can override host and port via environment variables HARIBON_HOST and HARIBON_PORT.
