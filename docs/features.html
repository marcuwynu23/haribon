Features

Everything you need for simple, observable request distribution.

Layer 7 (HTTP) Load Balancing

Routes HTTP requests to backend servers at the application layer. Full support for HTTP/1.1 reverse proxying via the standard library.

Round-Robin Scheduling

Distributes requests across your backend servers in a fair, cyclic order. Each request is routed to the next available server automatically.

Health-Aware Routing

Skips unhealthy servers automatically. Only healthy backends receive traffic, so your users always reach a working service. If all backends are down, Haribon returns a clear 503 error.

Structured JSON Logging

Outputs structured JSON logs with timestamp, method, path, backend, status code, and duration. Ready for ingestion by Loki, Elasticsearch, or any JSON-compatible log pipeline.

Loki & Promtail Integration

First-class support for the Grafana observability stack. Includes a Docker Compose file that sets up Haribon, Promtail, Loki, and Grafana with a single command.

Docker Support

Official images published to GitHub Container Registry. Run with a single docker run command or deploy via Compose alongside your backend services.

Environment Variable Overrides

Override host and port via HARIBON_HOST and HARIBON_PORT environment variables. Useful for containerized deployments and CI/CD pipelines.

Graceful Fallback Logging

If the configured log file cannot be created or written, Haribon automatically falls back to stdout. Ensures you never lose visibility into traffic.

Export Formats

Logs and metrics are delivered in standard formats ready for your existing pipeline.

JSON Logs

Structured JSON output with consistent schema. Each log entry includes time, method, path, backend, status, duration, and level. Compatible with Loki, Elasticsearch, and Datadog.

Stdout / File Output

Logs are written to both stdout and a configurable file simultaneously. File directories are auto-created. Falls back to stdout if file writing fails.
