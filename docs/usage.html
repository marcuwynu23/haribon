Usage

Start Haribon, send traffic, and observe the logs.

CLI

./haribon start --config haribon-config.yml

Flags

start
Start the load balancer
--config
Path to YAML configuration file

Example

With the default configuration, Haribon listens on port 4444 and distributes requests across three local backends.

# Start the load balancer
./haribon start --config haribon-config.yml

Send a request:

curl http://localhost:4444

Haribon proxies the request to one of the healthy backends using round-robin scheduling. Each request is logged as a structured JSON entry:

Log Output

{
  "time": "2026-05-04T01:31:55.3551454Z",
  "method": "GET",
  "path": "/",
  "backend": "http://localhost:4442",
  "status": 200,
  "duration_ms": 5,
  "level": "info"
}

Query Logs in Grafana

With the observability stack running, open Grafana (admin/admin) and query:

{job="haribon"}

Filter errors:

{job="haribon"} |= "error"

Tips

  • Haribon is stateless — run multiple instances behind another load balancer for high availability
  • Logs are written to both stdout and a configurable file, so you never lose visibility
  • Use HARIBON_HOST and HARIBON_PORT environment variables for containerized deployments
  • Pair with the included Docker Compose observability stack for instant Grafana dashboards
